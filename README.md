# dotfiles

Personal config, deployed as `~/.config/<dir>` (plain symlinks, no stow).

## Active stack

| Area | Tool | Notes |
|---|---|---|
| Compositor | **Hyprland** | Daily driver. Lua config (0.55+), entry point `hypr/hyprland.lua`. |
| Compositor (alt) | **niri** | Kept in parity with Hyprland's binds/autostart as a tested alternative, not the daily driver. |
| Desktop shell | **noctalia** | Bar, panels (launcher/clipboard/control-center), notifications, lock screen, wallpaper, theming. Replaces waybar/mako/rofi/dunst — see `noctalia/settings.json` and `hypr/noctalia.lua` (generated theme). |
| Idle/lock | **hypridle** | `hypr/hypridle.conf`. Delegates the actual lock/suspend action to `noctalia msg session ...` (not hyprlock). Spawned under both Hyprland and niri autostart. |
| Terminal | **kitty** | `kitty/kitty.conf`, theme generated by noctalia (`kitty/themes/noctalia.conf`). `alacritty` is kept only as a fallback bound to `XF86Launch3`. |
| Shell | **zsh** | `zsh/.zshrc`. |
| Multiplexer | **tmux** | One persistent session (`kitty tmux new -As1`), plugins via tpm (gitignored, not vendored). |
| Editor | **Neovim** | `nvim/`, native `vim.pack` plugin manager (Neovim 0.12+, no bootstrap), lazy-loaded — see `nvim/lua/core/pack_loader.lua`. |
| Prompt | **starship** | Catppuccin Mocha palette. |
| App launcher | **wofi** (`Mod+D`) + noctalia's own launcher (`Mod+Space`, both compositors) | Kept both; wofi is faster for raw drun, noctalia's launcher integrates with its other panels. |
| Music | **mpd** + **ncmpcpp** | mpd autostarted; ncmpcpp is a manual TUI client. |
| System info banner | **fastfetch** | Runs once per outer terminal attach (gated on `$TMUX` so it doesn't repeat per pane). |

## Legacy / not in use

`i3/`, `picom/`, `polybar/`, `waybar/`, `mako/` — pre-noctalia, pre-Hyprland-migration configs. Nothing in the active Hyprland/niri/noctalia autostart references them, no systemd units are enabled for them, no processes run. Kept for reference/rollback, not maintained. If reviving any of these, update this table.

## Structure notes

- `noctalia/plugins/<name>/` (`clipper`, `tailscale`) are vendored copies of those plugins' upstream repos, not hand-written config — same category as `tmux/plugins/*`, just not yet gitignored the same way.
- `noctalia/plugins/clipper/notecards/*.json` is clipboard-history user data (can contain anything ever copied, including secrets) — already excluded via a nested `.gitignore` in that plugin directory. Don't remove that exclusion.
- `hypr/noctalia.lua` is regenerated by noctalia whenever the color scheme/wallpaper changes; expect it to show a diff after theme changes.
- Version pins that matter (don't "helpfully" bump): `neo-tree.nvim` → `v3.x` branch, `telescope.nvim` → `0.1.8` tag, `nvim-treesitter` → `main` branch, `blink.cmp` → `1.x`. See `nvim/lua/core/plugins.lua`.
